StockScan - Android WebView (نسخة تست)

الطريقة 1: Android Studio
  افتح المجلد > Sync > Build > Build APK(s)
  الملف: app/build/outputs/apk/debug/app-debug.apk

الطريقة 2: GitHub Actions (بدون تثبيت أي شيء)
  ارفع محتوى المجلد إلى مستودع GitHub جديد.
  تبويب Actions > Build Test APK > Run workflow
  بعد دقيقتين حمّل StockScan-debug-apk من Artifacts.
